# 获取源码与运行现状

状态：2026-09-25 的源码检查结果。当前根仓锁定的学生端和教师端内 Core 提交在可取得的远端历史中缺失，**尚不能保证按根仓锁定版本完成安装和运行**。Windows 原生构建、macOS 教师端与中继模式均未完成验证；后两者属于[目标设计](/architecture/teacher-cross-platform-relay)，不是当前启动选项。

## 环境

- Git、Node.js 和 pnpm 10.33.0。根仓声明 pnpm 版本，未统一固定 Node.js 版本。
- 当前教师和学生桌面壳均为 Windows 构建：需要 CMake、Visual Studio C++ 构建工具、WebView2 SDK/Runtime 与 PowerShell。具体安装和打包结果尚待 Windows 设备验证。
- 文档站和下载站是根仓独立项目；它们不等于课堂服务。

## 获取源码

```bash
git clone https://github.com/yc004/SyncClassroom.git
cd SyncClassroom
git submodule status
```

通常可用 `git submodule update --init --recursive` 取得锁定子模块，但**当前该命令可能因学生端、Core 和旧 AI Editor 的失效指针而失败**。旧 AI Editor 与 VS Code 插件均退出目标架构，不建议为了运行新方案额外克隆旧编辑器。已经取得的本地源码组合和准确 SHA 见[子模块状态](/status/submodules)。在指针修复和兼容测试完成之前，不应将可访问的远端最新提交误当成项目锁定版本。

当所需包和锁定文件都可用时，安装依赖的命令是：

```bash
pnpm install --no-frozen-lockfile
```

工作区包含根目录、`packages/`（共享契约包）、`docs-site`、`website`、`repos/teacher`、`repos/teacher/core` 与 `repos/student`；`repos/teacher`、`repos/student` 通过 `workspace:*` 引用契约包，因此改动契约后必须重新安装以重建链接。`pnpm install` 仅安装 JavaScript 依赖，不构建 Windows 桌面壳。

## 当前脚本入口

| 命令 | 当前作用 | 运行条件与状态 |
| --- | --- | --- |
| `pnpm run start:teacher-server` | 启动教师 HTTP/Socket.IO 服务 | 需要教师端与 Core 可用；已通过 HTTP/协议层自动化测试，两端连课仍未实测 |
| `pnpm run start:teacher` | 启动现有 Windows 教师桌面壳 | 需要先得到 `LumeSyncTeacherShell.exe`；macOS 端尚未实现 |
| `pnpm run start:student` | 启动现有 Windows 学生桌面壳 | 需要先构建学生端；当前学生端与根仓指针不匹配 |
| `pnpm run start:core` | 启动独立 Core runtime | 需要 Core 构建产物；它不是完整教师课堂服务 |
| `pnpm run test` | 契约包测试 + 教师服务测试 | 覆盖协议握手、越权拒绝、课程校验与会话引导回归 |
| `pnpm run docs:dev` | 启动文档站 | 只需文档站依赖；站点构建时从 `docs/` 同步内容 |
| `pnpm run start:website` | 启动下载站 | 需要 `WEBHOOK_SECRET`；默认端口可能与教师服务冲突 |

根 `package.json` 不再保留旧 AI Editor 与 VS Code 插件脚本，两者也都不进入[目标架构](/architecture/target-architecture)。

启动教师服务后，可用 `GET /api/health` 与 `GET /api/protocol` 确认协议版本（当前 `protocolVersion: 1`）与事件清单；客户端连接时应在 Socket.IO `auth` 中带上 `protocolVersion`。详见[共享契约包](/reference/contracts)。

## 当前课堂链路

现有实现中，教师服务提供课程、页面和 Socket.IO 课堂事件；学生端配置教师机的局域网地址。教师端选课、翻页、互动和提交功能已能从源码定位，**尚未在当前不匹配的提交组合上完成端到端验证**。具体模块与风险见[源码级评估](/architecture/source-review)。

## 常见问题

- **子模块无法初始化**：先查看[子模块状态](/status/submodules)，不要直接更新到远端最新提交并宣称版本兼容。
- **找不到 Windows `.exe`**：启动脚本不是构建脚本，需要在 Windows 环境完成原生构建。
- **学生无法连接**：检查教师服务是否启动、两机 IP/端口、防火墙和学生端地址配置；当前没有完整的自动连课验证结果。
- **端口占用**：教师服务与下载站均可能使用 3000 端口，需分别配置。
- **搜索不到教室中继**：自发现和验证码连接仍处于[设计阶段](/architecture/teacher-cross-platform-relay)，当前版本没有此功能。
