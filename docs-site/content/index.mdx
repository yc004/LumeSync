## 当前状态

| 项目 | 状态 |
| --- | --- |
| 现有教师端 | Windows C++/WebView2 壳、React 界面、Node.js/Express/Socket.IO 服务；源码已静态审查，Windows 构建未实测 |
| Electron 教师桌面壳 | `apps/teacher/desktop`：已在 macOS 上运行直接模式源码预览（加载现有 React 界面并自起本机教师服务）；中继接线、安装包与 Windows 实机未验证 |
| 现有学生端 | Windows 壳位于 `apps/student/desktop`；课堂页位于 `apps/student/ui/classroom`，构建为版本化产物供教师服务分发；跨机实测待完成 |
| 课件运行时 | `packages/course-runtime` 保留 `@lumesync/core` 包名，支持 ZIP `.lume` 与旧格式；旧 TSX/JS 路径仍需隔离 |
| 教室 Hub 与会话代理 | `apps/classroom-hub`（direct / relay 两种模式）与 `apps/teacher/session-agent` 已完成首轮落地并有自动化测试；**缺 TLS/WSS、Hub 持久化、固定机只读投影与跨机实测** |
| 新编辑器 | `apps/editor` 已有 Electron MVP、受限声明式组件、`.lume` 打包和用户自带模型 API；完整编辑工作流、代码扩展和发行验收待完成 |

除本导航首页外，本站的当前说明页面均由根目录 [`docs/`](https://github.com/yc004/LumeSync/tree/main/docs) 同步生成。当前状态以[实施 TODO](/status/todo)和各模块测试结果为准；端到端联调仍待进行。旧站点页面已[归档](https://github.com/yc004/LumeSync/tree/main/docs/archive/docs-site-pre-sync)，不作为当前规范。
