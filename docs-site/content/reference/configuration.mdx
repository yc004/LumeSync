# 配置、目录与环境变量

状态：**当前源码默认值**，依据 `repos/teacher/server/src/config.js`、`server/index.js`、两端 Windows 壳和 `website/server.js`。相对路径以下均相对教师仓库或对应服务。公开部署前需先处理[安全缺口](/architecture/runtime-mechanisms#信任边界与现状风险)。

## 教师 Node 服务

| 变量 | 默认或作用 |
| --- | --- |
| `PORT` | `3000`；HTTP 与 Socket.IO 共用 |
| `LUMESYNC_PUBLIC_DIR` / `STATIC_DIR` | 公共资源根；前者优先，默认 `shared/public` |
| `LUMESYNC_DOCS_ROOT` | 旧课件开发文档根，默认 `shared/docs` |
| `LUMESYNC_COURSES_DIR` | 课程文件，默认 `shared/public/courses` |
| `LUMESYNC_FOLDER_DATA_PATH` | 文件夹元数据，默认 `shared/public/data/course-folders.json` |
| `LUMESYNC_CLASSROOM_LAYOUT_PATH` | 座位布局，默认 `shared/public/data/classroom-layout-v1.json` |
| `LUMESYNC_SUBMISSIONS_DIR` | 默认提交根目录，默认 `repos/teacher/submissions` |
| `LUMESYNC_SUBMISSIONS_CONFIG` | 提交目录选择记录，默认 `repos/teacher/submissions-config.json` |
| `SUBMISSIONS_DIR` | 实际提交目录的进程环境覆盖值；启动时可被上述配置文件写入 |
| `LUMESYNC_CACHE_DIR` | 总缓存根，默认公共资源根 |
| `LUMESYNC_LIB_DIR`、`LUMESYNC_WEIGHTS_DIR`、`LUMESYNC_IMAGES_DIR`、`LUMESYNC_WEBFONTS_DIR` | 各类依赖缓存目录，默认位于缓存根下对应子目录 |
| `LUMESYNC_SKILL_PATH`、`LUMESYNC_COURSE_GUIDE_PATH` | `/api/download-skill`、`/api/course-guide` 下载的源文件 |
| `LUMESYNC_STUDENT_LOG_MAX` | 进程内学生日志上限，默认 `500` |
| `LUMESYNC_ANNOTATION_MAX_SEGMENTS_PER_SLIDE` | 每页标注上限，默认 `5000` |
| `LUMESYNC_STUDENT_UI_DIR` | 学生课堂 UI 构建产物目录覆盖（默认由工作区包 `@lumesync/student-ui` 的 `exports("./dist")` 解析，即 `repos/student/ui/classroom/dist`）；见下节 |
| `LUMESYNC_SERVER_PID_FILE` | 可选 PID 文件，服务启动写入、退出删除 |

服务启动会创建公共目录、缓存、课程、布局父目录和提交目录；`POST /api/submission-config` 会更新目录并写配置文件。静态 bundle 与 `/protocol-client.js`（协议版本与事件清单，由 `packages/classroom-protocol` 生成）启动时按需重建；`/teacher-app.js`、`/render-engine.js` 以 no-store 提供。Socket 心跳固定为 `pingInterval=5000ms`、`pingTimeout=8000ms`，HTTP JSON 限制 2 MB；当前不是环境变量配置项。

## 学生课堂 UI 构建产物

正式课堂页由学生端仓库构建，教师服务只分发（见[目标架构 §6 模块归属](/architecture/target-architecture)与[迁移状态](/status/migration)）。

| 项 | 值 |
| --- | --- |
| 源码 | `repos/student/ui/classroom/src/{index.html,classroom-app.js}`（工作区包 `@lumesync/student-ui`） |
| 构建命令 | `pnpm --filter @lumesync/student-ui run build`（等价于 `node repos/student/ui/classroom/scripts/build.mjs`） |
| 默认产物目录 | `repos/student/ui/classroom/dist`（由 `require('@lumesync/student-ui/dist')` 导出的 `distDir` 给出，也可用 `require.resolve` 定位） |
| 版本方案 | `dist/<package version>-<构建输入 sha256 前 12 位>/`，例如 `dist/1.0.0-56532f8953d1/`；内容不变时重复构建版本不变 |
| 指针文件 | `dist/current.json`（`{version, dir, entry, manifest}`）与 `dist/manifest.json`（`{version, files:[{path,size,sha256}], entry}`） |
| 覆盖变量 | `LUMESYNC_STUDENT_UI_DIR` 指向任意等价的产物目录（同样需要 `current.json` + `manifest.json`）；测试与离线部署用 |

教师服务启动时检查该产物（不重新构建、不做 Babel 编译）：产物缺失或损坏时日志给出预期路径与构建命令，`GET /student.html`、`GET /classroom/*` 返回 503，不静默 404、不回退旧副本。产物目录不在 Git 中（`dist/` 被忽略），部署前必须先构建。

## 会话配置

| 变量 | 当前行为 |
| --- | --- |
| `LUMESYNC_HOST_TOKEN` | host 共享凭证；独立启动时若未设置，由服务随机生成；Windows 教师壳会注入 |
| `LUMESYNC_VIEWER_TOKEN_SECRET` | viewer token HS256 密钥；独立启动时若未设置，由服务随机生成；Windows 教师壳会注入 |
| `LUMESYNC_VIEWER_TOKEN_TTL_SEC` | viewer token 默认 `14400` 秒 |
| `LUMESYNC_HOST_TOKEN_TTL_SEC` | **已废弃**：源码中不再读取。host bootstrap 现返回 `expiresAt: null`，Socket 只比较共享 token |
| `LUMESYNC_IDENTITY_LEGACY_COMPAT` | **Core 独立 runtime** 的兼容身份开关，默认开启；不是教师业务服务的统一配置 |
| `LUMESYNC_PROTOCOL_ALLOW_UNDECLARED` | 教师服务 Socket 是否放行不在[契约事件表](/reference/contracts)中的事件；默认关闭（拒绝）。仅在旧客户端过渡窗口临时开启 |

随机密钥在进程重启后改变；如果需要复现会话，应显式持久化或注入相同材料。host bootstrap 现在只接受带本机凭证的 loopback 请求，viewer 分支签发短期凭证；不要把凭证提交到 Git。

## 教室 Hub（`apps/classroom-hub`）

两种模式由 `LUMESYNC_HUB_MODE` 选择：`direct`（默认，教师电脑，host token 直连）与 `relay`（教室固定机，验证码配对 + 唯一授课租约）。
完整接口与事件见[教室 Hub](/reference/classroom-hub)；容量与有效期的默认值一律取自共享契约的常量。

| 变量 | 默认或作用 |
| --- | --- |
| `LUMESYNC_HUB_MODE` | `direct`（默认）或 `relay`；其他值直接抛错 |
| `PORT` | `3000`；HTTP 与 Socket.IO 共用（`0` = 系统分配，测试用） |
| `LUMESYNC_HUB_HOST` | `0.0.0.0` |
| `LUMESYNC_HUB_CLASSROOM_ID` | 稳定设备 ID，默认 `classroom-<主机名>`（转成 DNS-SD 安全字符）；写入发现 TXT |
| `LUMESYNC_HUB_CLASSROOM_NAME` | 教室显示名，默认主机名 |
| `LUMESYNC_HOST_TOKEN` | 管理/host 凭证；与教师服务同名。中继模式下只在本机回环请求上作为管理凭证（屏幕内容、host 引导、本机上传） |
| `LUMESYNC_HUB_TOKEN_SECRET` | 设备凭证与 viewer 凭证的 HMAC 密钥，未设置时进程随机 |
| `LUMESYNC_VIEWER_TOKEN_TTL_SEC` | viewer 凭证有效期，默认 `14400` 秒 |
| `LUMESYNC_HUB_DEVICE_TOKEN_TTL_SEC` | 配对签发的设备凭证有效期，默认 `28800` 秒 |
| `LUMESYNC_HUB_CAN_DISPLAY_CODE` | `1`（默认）；`0` 表示固定机没有可用屏幕：中继进入 `error`，屏幕接口返回 `relay_no_screen`，绝不降级为无验证码连接 |
| `LUMESYNC_HUB_DISCOVERY` | relay 模式默认 `1`、direct 模式默认 `0`；是否发布 mDNS |
| `LUMESYNC_HUB_DISCOVERY_SERVICE_TYPE` | `_lumesync-relay._tcp.local` |
| `LUMESYNC_HUB_LEASE_TTL_MS` | 授课租约 TTL，默认契约的 `60000`；过期后课堂进入等待教师 |
| `LUMESYNC_HUB_SWEEP_INTERVAL_MS` | 过期清理周期，默认 `1000`（`0` = 关闭定时器） |
| `LUMESYNC_HUB_STAGE_MAX_BYTES` | 课件上传与暂存上限，默认契约的 512MiB；超过时 HTTP 返回 413 `stage_capacity_exceeded` |
| `LUMESYNC_HUB_STAGE_MAX_VERSIONS` | 暂存版本数上限，默认契约的 `20` |
| `LUMESYNC_HUB_STAGE_TTL_MS` | 暂存过期，默认契约的 24 小时（正在播放的版本不清理） |
| `LUMESYNC_HUB_QUEUE_CAPACITY` | 提交转发队列容量，默认契约的 `200`；满时明确返回 `queue_full` |
| `LUMESYNC_HUB_QUEUE_TTL_MS` | 队列条目过期，默认契约的 24 小时 |
| `LUMESYNC_HUB_JSON_LIMIT` | JSON 请求体上限，默认 `2mb` |
| `LUMESYNC_HUB_SOCKET_MAX_BYTES` | Socket.IO 单包上限，默认 `2097152`；契约允许截图 dataUrl 到 1.4MB，Socket.IO 默认的 1MB 会在传输层直接断连 |
| `LUMESYNC_PROTOCOL_ALLOW_UNDECLARED` | 与教师服务同名同义：是否放行契约未声明的事件，默认关闭 |
| `LUMESYNC_HUB_LOG_LEVEL` | `silent` / `error` / `warn` / `info`（默认）/ `debug` |

验证码有效期（3 分钟）与尝试次数（5 次）固定由契约决定，不提供环境变量覆盖。Hub 当前不写任何文件：课堂状态、租约、暂存课件与提交队列都在进程内存，重启即丢失（见[教室 Hub §5](/reference/classroom-hub)）。Hub 打开 `PORT` 端口的入站监听；`relay` 模式还需要 UDP 5353 组播可用，组播不可用时发现会记录明确错误，教师端改用手动地址。

## 本地壳与下载站

教师 Windows 壳保存教师 IP/端口、密码哈希、窗口/课堂设置，负责启动 Node 子进程并注入会话环境变量。学生 Windows 壳保存教师 IP/端口、clientId、viewer 会话、开机自启/守护/全屏配置；守护服务在相应开关启用时周期拉起学生壳。两端均有管理密码哈希，属于本机配置，**不等同于服务端 HTTP 授权**。

下载站使用自己的 `PORT` 和 `WEBHOOK_SECRET`，以 GitHub webhook 更新 `downloads/version.json` 与下载资产；它不是教师服务的 API 路由。三个服务默认端口均可为 3000，分别运行时需要避免冲突。完整路由见 [HTTP API](/reference/http-api)。
