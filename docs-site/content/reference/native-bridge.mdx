# Windows 原生壳与 WebView2 桥接 API

状态：**当前源码实现**，依据两端 `native/shell/src/main.cpp` 与[共享契约](/reference/contracts) `packages/native-contract`，尚未在 Windows 实机联调。教师和学生原生壳均为 C++/WebView2；`window.electronAPI` 只是兼容别名，不表示使用 Electron。计划中的 Windows/macOS 教师端桥接接口尚未实现。

## 消息封装

页面通过 `window.chrome.webview.postMessage` 发送：

```json
{"kind":"rpc","id":"rpc-...","action":"getConfig","payload":{}}
```

或单向通知：

```json
{"kind":"event","action":"classStarted","payload":{}}
```

原生 RPC 回传 `{kind:'rpc-result', id, ok, payload, error?}`。JS 用 `id` 匹配待处理 Promise，10 秒无回传即超时；`ok:false` 会 reject。单向事件没有成功回执。原生壳也可主动发 `window-maximized` / `window-unmaximized` 给教师页。消息没有协议版本字段。

## 教师桥 `window.teacherHost`

| 方法 | 形态 | 当前作用 |
| --- | --- | --- |
| `getConfig()`、`saveConfig(config)`、`verifyPassword(password)` | RPC | 读取/保存本机教师 IP、端口、密码哈希；按 SHA-256 哈希验证管理密码 |
| `getSession()`、`bootstrapSession()` | RPC | 读取会话或经本机服务 bootstrap 获取 host 会话 |
| `getSettings()`、`saveSettings(settings)` | RPC | 读取/保存窗口和课堂设置，包括跟随、交互、全屏、监看间隔 |
| `importCourse()`、`exportCourse(payload)`、`saveGeneratedPdf(payload)` | RPC | 本机课程文件选择、导入/导出和 PDF 写入 |
| `openLogDir()`、`getLogDir()` | RPC | 打开/取得本机日志目录 |
| `selectSubmissionDir()` | RPC | **当前返回 `null`，尚未实现目录选择** |
| `getRole()` | 本地 Promise | 固定返回 `host`，不经原生消息 |
| `classStarted(options)`、`classEnded()`、`setFullscreen(enable)` | 单向事件 | 课堂生命周期和窗口全屏 |
| `toggleDevTools()`、`minimizeWindow()`、`maximizeWindow()`、`closeWindow()` | 单向事件 | 窗口操作 |
| `openWindow(url, options)`、`beginWindowDrag()`、`updateWindowDrag()`、`endWindowDrag()` | 单向事件 | 多窗口及拖动 |
| `onWindowMaximized(cb)`、`onWindowUnmaximized(cb)` 及移除方法 | 本地监听 | 接收原生窗口状态通知 |

`saveSettings` 接收的已实现字段包括 `forceFullscreen`、`syncFollow`、`allowInteract`、`syncInteraction`、`podiumAtTop`、`renderScale`、`uiScale`、四种提醒开关、`monitorEnabled` 和 `monitorIntervalSec`；监看间隔裁剪为 0.5–5 秒。`saveConfig` 会重新导航页面。

## 学生桥 `window.studentHost`

| 方法 | 形态 | 当前作用 |
| --- | --- | --- |
| `getConfig()`、`saveConfig(config)`、`verifyPassword(password)` | RPC | 读取/保存教师机地址、端口、全屏、守护开关等；管理密码校验 |
| `getAutostart()`、`setAutostart(enable)` | RPC | 获取/设置本机开机自启配置 |
| `getSession()`、`bootstrapSession()` | RPC | 获取/刷新 viewer 会话；原生层通过 WinHTTP 访问教师服务 |
| `getDeviceInfo()` | RPC | 返回设备名、MAC、clientId 等身份资料 |
| `takeScreenshot({maxWidth?,quality?})` | RPC | GDI+ 截屏并返回 JPEG data URL 及尺寸 |
| `powerControl({action})` | RPC | 执行本机关机/重启等受支持动作 |
| `getRole()` | 本地 Promise | 固定返回 `viewer` |
| `classStarted()`、`classEnded()`、`setFullscreen(enable)`、`manualRetry()`、`setAdminPassword(hash)` | 单向事件 | 课堂状态、重连、管理密码下发 |
| `toggleDevTools()`、`minimizeWindow()`、`maximizeWindow()`、`closeWindow()` | 单向事件 | 窗口操作 |

学生桥还暴露 `getSettings`、`saveSettings`、`importCourse`、`exportCourse`、`openLogDir`、`getLogDir`、`selectSubmissionDir` 兼容方法，**都仅返回 `null`**，不能视为学生端功能。学生页面接到 Socket 的 `student:power-control` 后才会调用 `powerControl`。

## 安全与移植边界

WebMessage 消息格式只封装了动作名称，没有 origin/能力声明。学生壳会导航到配置中的教师 URL，且源码中的 WebView2 `PermissionRequested` 处理器直接允许请求。原生桥同时涉及文件系统、屏幕与电源，迁移到 macOS 或中继架构时应重新设计可信页面来源、动作白名单、用户授权和回执语义。当前 API 是迁移清单，不是目标跨平台接口保证。见[教师端目标设计](/architecture/teacher-cross-platform-relay)。

## 共享契约与能力清单

两端桥的类型与动作清单现在由[共享契约](/reference/contracts) `packages/native-contract` 单点维护：消息封装 `{kind, id, action, payload, version}`、回执 `{kind:'rpc-result', id, ok, payload, error}`、RPC 超时 10 秒、payload 上限，以及按角色的动作表（`kind`、`transport`、`implemented`、`nativeDispatch`、`risk`）。

`repos/teacher/shared/protocol/teacher-host.ts`、`repos/student/shared/protocol/student-host.ts` 与 `repos/student/ui/student-host/src/types.d.ts` 现在只从这里再导出类型。契约测试会读取两端 `native/shell/src/main.cpp` 的动作分派并与清单对照；目前仍有一处已知缺口：

| 端 | 问题 | 影响 |
| --- | --- | --- |
| 教师壳 | 注入脚本暴露 `classStarted`、`classEnded`、`setFullscreen`，但 `HandleEvent` 没有对应分支 | 课堂开始/结束与全屏调用被静默丢弃 |

教师壳缺口在能力清单中标记为 `implemented: false` 并附说明。学生壳 `maximizeWindow` 已接入 C++ 分派，仅在非授课状态切换窗口最大化；Windows 实机编译仍待验证。**消息版本字段尚未落地**：契约要求消息带 `version`，两端 C++ 壳目前不发送，原生壳仍只按 `action` 字符串分派、不校验消息来源。
