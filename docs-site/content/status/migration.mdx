迁移应按“可构建基线 → 授权和隔离 → 共享契约 → 跨平台直接模式 → 中继模式 → 新编辑器”的依赖顺序推进。某个代码入口通过单元测试不等于整端功能完成；每项需分别经过桌面构建、多机课堂操作和异常恢复验证。

提交链路的后续加固：中继只向当前有效授课租约持有者转发学生事件与提交，也只接受该设备的落盘回执；获取或续期租约时主动重放 Hub 内尚未确认落盘的提交。教师会话代理在断线后清除本连接的去重记录，让重放再次通知教师界面。队列仍只在内存，**Hub 进程重启后的恢复未实现**。
