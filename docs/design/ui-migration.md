## 执行顺序

1. 先建立共享主题接入方式与最小组件样例：按钮、状态标记、文本输入、提示、空白/错误态。原生窗口控件不重画。
2. 先改课堂的连接、控制、提交和离线流程，再改座位管理及编辑器复杂面板；每批以真实任务闭环验收。
3. 每改一个客户端，同时替换该客户端新增的硬编码 token，验证浅/深/高对比和减少动效；不要求一次性清除全部旧代码。
4. 组件复用需先证明语义和键盘行为相同。教师课堂、学生页面和固定机投影可共享 token 与状态文案，但保留不同密度、尺寸和导航。
